# pilardelpuerto.com

Web de Pilar del Puerto, publicada con GitHub Pages.

- Cada página es una carpeta con su `index.html` (por ejemplo, `bio/index.html`).
- `en/` contiene la versión del selector de idioma EN (mismo contenido).
- `media/` guarda las imágenes y los vídeos; `assets/` la hoja de estilos, el script y las tipografías.
